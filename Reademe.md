# Custom Encoder-Only Transformer for SMS Spam Classification

A scratch-built encoder-only Transformer architecture written in PyTorch to classify SMS messages as Spam or Ham using the `codesignal/sms-spam-collection` dataset. 

## Features
- Custom-built Multi-Head Attention, Layer Normalization, and Feed-Forward Blocks.
- Positional encodings implemented from scratch.
- Achieves ~97%+ validation accuracy.
